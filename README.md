# DNDFightSimulate

基于 **Unity / C#** 的 D&D 2024 战斗数值模拟器。配置角色、职业和武器，在网格训练场中与木桩战斗，通过立体骰子和战斗日志查看结算过程。

## 运行

1. 使用 **Unity 2022.3.62f3c1** 打开仓库根目录。
2. 打开 `Assets/Scenes/Main.unity`，点击 **Play**。
3. 进入战斗，选择地图、配置角色并部署棋子后开始。

Windows 程序通过 **File > Build Settings > Build And Run** 构建。

## 核心功能

- **角色配置**：六项属性、种族配置与部分主被动特性、12种职业、多职业等级、背景及技能／工具熟练。
- **武器战斗**：39个武器条目，支持灵巧、轻型、近战触及和远程射程。
- **回合操作**：动作、附赠动作、移动、反应、额外攻击及借机攻击。
- **地图与表现**：三种地图规格，拖动移动，酒馆界面、角色铭牌、立体／简洁投骰及独立音量设置。
- **法术与状态**：攻击、豁免、伤害类型、治疗、专注、光照、隐形和部分变形效果。
- **战后流程**：倒地、死亡豁免、部分复活法术、休息及手动继续战斗。

首次有效战斗操作后锁定基础配置；“重置战斗”恢复生命与资源并重新部署。返回菜单保留当前战斗，尚无战斗存档。

## 当前范围

法术目录共 **391项**：101项已接入结算、6项仅供学习、284项待接入。部分战士能力与10种地面荒野形态可用；48项子职业目前仅保存选择，不自动生效。

水域与呼吸、遗体搬运、召唤物及多单位流程仍在开发。飞行、环境物件、位面、法术位资源及完整职业能力尚未全部实现。

项目含训练场专用裁定，并非完整的2024规则引擎。开发说明包含工作区中尚未提交的内容，具体实现范围请查看下列文档。
