# DNDFightSimulate

项目已迁移至 Unity，后续统一使用 Unity / C# 开发。

## 打开与运行

使用 **Unity 2022.3.62f3c1** 打开仓库根目录，打开 `Assets/Scenes/Main.unity`，点击 Play。
通过 File > Build Settings 选择 Windows 平台并 Build And Run 可运行独立程序。

## 功能

- 主菜单：进入战斗、设置、退出游戏。
- 木桩 1000 血量，仅被动承伤。战斗界面左下角可实时选择长剑（双手，1d10）、长剑（单手，1d8）或短剑（1d6），默认长剑（双手）。攻击展示对应骰子的滚动过程，最终点数为本次伤害。
- 投掷期间禁用攻击、结束回合和返回，避免重复结算；武器仍可切换，本次按点击攻击时的武器结算，新武器下次生效。
- 结束回合木桩反击，双方血量保留；任一方死亡后双方恢复满血。返回菜单保留当前战斗。
- 合成背景音乐和投骰音效，独立音量滑块、音效试听，PlayerPrefs 保存音量。
- 退出游戏关闭独立程序；编辑器内停止 Play。

## 结构与验证

- `Assets/Scripts/CombatState.cs`：血量和回合规则。
- `Assets/Scripts/TrainingGame.cs`：界面、投骰动画、声音与设置。
- `Assets/Editor/ProjectSetup.cs`：创建主场景，并验证伤害、血量下限、回合重置和骰值范围。

批处理验证入口：`-batchmode -nographics -quit -projectPath <项目路径> -executeMethod ProjectSetup.CreateAndVerify -logFile <日志路径>`。
该命令会重新生成主场景，仅适用于初始场景搭建。旧 Python 和网页版本保留在 Git 历史中。

## 回合反击与配置

玩家初始 100 血，木桩 1000 血。结束回合时木桩按 D4/D6/D8/D10/D12 的数量与固定加值反击，全部默认 0。负伤害按 0 结算。双方不在回合结束时回血，任意一方死亡后双方恢复满血，回合重置为 1。

左下角“玩家武器”打开可关闭的选择面板；右侧“怪物伤害更改”打开配置面板，填写后点击“应用”，右上角可关闭。骰子数量为非负整数，固定加值允许负数。单次骰子总数最多 10000，防止输入过大导致卡顿。


## 玩家属性

战斗界面左下角，“玩家武器”上方的“玩家属性”打开编辑面板，右上角关闭。力量、敏捷、体质、感知、智力、魅力均默认 10，仅接受 3～20 的整数，点击应用统一保存；目前不影响战斗结算。属性和怪物伤害输入框拒绝小数，怪物固定加值仍可输入负整数。音量以整数百分比调整。

所有玩家武器伤害 = 原武器骰值 + floor((力量 - 10) / 2)，最终伤害最低 0。力量修正允许负数，例如力量 3 为 -4、9 为 -1、10 为 0、20 为 +5。武器和力量修正在点击攻击时锁定，动画期间修改从下次攻击生效。伤害显示包含原骰值、力量修正和最终伤害。

## 玩家职业与生命上限

战斗界面“玩家职业”打开战士/法师选择与等级编辑面板，右上角关闭。默认选中战士；战士 1 级、法师 0 级，各职业等级为 0～20 整数，等级总和至少为 1，点击应用后生效。职业暂不提供额外能力。

生命上限 = (6 + floor((体质 - 10) / 2)) × (战士等级 + 法师等级 - 1) + 10 + floor((体质 - 10) / 2)。默认生命为 10/10。修改体质或职业等级仅调整上限，保留当前血量，超过新上限才截断；死亡后的恢复使用新的上限。

## 怪物属性与生命上限更新

怪物属性按钮位于怪物伤害更改下方，右上角可关闭面板。六项属性默认 10，限 3～20 的整数；最大 HP 默认 1000，限至少为 1 的整数。点击应用后生效。怪物六项属性暂不参与伤害公式。

此规则替代此前保留当前血量的规则：双方最大 HP 实际改变时，当前血量同时回满至新上限；上限未变时不回血。玩家属性仍在左下角玩家武器上方。

## 命中判定

双方护甲等级暂固定为整数 10。玩家攻击和回合结束时木桩反击均先投 1d20，骰值大于等于目标护甲才命中；未命中不投伤害骰、不扣血。判定无额外修正或暴击规则。玩家显示 D20 投掷过程，双方日志显示最终命中骰值、目标护甲及命中/未命中结果。

怪物属性面板新增护甲等级：默认 10，范围 5～30 且必须为整数，点击应用后用于玩家的命中判定。仅修改护甲不会恢复血量。玩家护甲仍固定为 10。

命中判定特殊规则（双方通用）：自然 1 必定未命中，自然 20 无视护甲必定命中并暴击。暴击增加一组独立伤害骰：玩家武器从 1dN 变为 2dN，怪物每种伤害骰数量翻倍；力量修正和怪物固定加值均只加一次。伤害最终仍最低为 0。日志显示暴击与实际骰子数量。

## 初始职业和多职业生命（替代此前按总等级统一计算的规则）

增加游侠，默认 0 级；默认初始职业仍为战士，战士 1 级、法师 0 级。职业面板点击职业按钮选择初始职业，填写等级后点击应用。各职业等级限 0～20 的整数，初始职业至少 1 级，所有等级之和至少 1。

初始职业首级生命：战士/游侠为 10 + 体质修正，法师为 6 + 体质修正。扣除初始职业的第一级后，每级战士/游侠增加 6 + 体质修正，每级法师增加 4 + 体质修正。体质修正向下取整，初始职业与等级共同应用；修改体质后也按已应用的职业配置重算，上限改变时回满。职业暂无额外能力。
