# DNDFightSimulate

基于 Unity / C# 的跑团战斗数值模拟器。玩家可以配置属性、职业和武器，与可配置血量、护甲及反击伤害的训练木桩进行战斗。

## 运行方式

1. 使用 **Unity 2022.3.62f3c1** 打开仓库根目录。
2. 打开 `Assets/Scenes/Main.unity`。
3. 点击 **Play** 运行。

生成 Windows 独立程序：在 **File > Build Settings** 中选择 Windows 平台，使用 **Build And Run**。

## 主菜单与声音设置

| 按钮 | 功能 |
| --- | --- |
| 进入战斗 | 选择地图、拖动部署并开始战斗；已有未重置战斗时返回该战斗 |
| 设置 | 调整音乐、音效音量，并试听投骰音效 |
| 退出游戏 | 关闭独立程序；在编辑器内停止 Play |

背景音乐和投骰音效由程序合成，无需外部音频素材。音乐、音效音量独立控制，以整数百分比调整，通过 PlayerPrefs 保存，下次启动继续使用。设置还提供标准与快速两档立体投骰动画，选择会保存。

## 视觉与交互

界面采用暖色酒馆桌面：深棕木纹、米黄羊皮纸、黄铜边框与暗红按钮。主菜单由桌面纹章卡、立体骰子及进入战斗、设置、退出按钮组成。

战斗界面两侧是竖向金属纹章铭牌：玩家使用精致金铜，怪物使用粗糙旧铁。卡牌去除棋子，玩家以初始职业代表物件为主体，怪物使用木桩靶心。生命使用红色宝石与 HP 数字，护甲值铭刻在金属横带。受伤时宝石短暂闪红，治疗时闪绿，无飘字或震动。

中央展示有面值的立体多面骰，滚动停稳后朝向结果面。标准动画每次约 1.4 秒，快速约 0.45 秒；命中骰与伤害骰分别展示。骰值由规则随机生成，动画用于呈现结果。怪物同类伤害骰超过两个时，立体展示其中前两骰，卷轴记录全部骰子的合计。

中央底部羊皮纸卷轴保留本次运行内的全部战斗记录，支持滚动查看。布局按 1600×900 设计，窗口变化时等比缩放并保留比例。

## 地图与初始部署

| 地图 | 格数 | 地图边长 |
| --- | --- | --- |
| 小地图 | 10×10 | 50 尺 |
| 中地图 | 15×15 | 75 尺 |
| 大地图 | 20×20 | 100 尺 |

从主菜单进入战斗后，选择地图并拖动蓝色玩家棋子、红色木桩棋子到所需格子。双方必须在地图内并占据不同格子；无效拖放保留原位置。点击“开始战斗”锁定地图与初始部署，战斗期间木桩位置不能调整；玩家可按每回合移动力移动。部署时也可通过角色卡编辑配置，首次战斗操作后锁定数值。

每格代表 5 尺。距离按格心之间的直线距离计算：`round(5 × sqrt(横向格差² + 纵向格差²))`，四舍五入显示整数尺，横竖相邻为 5 尺、斜向相邻为 7 尺。距离显示在部署及战斗地图旁，玩家武器攻击按近战范围限制。

战斗地图位于中央，投骰动画覆盖显示在地图上方，两侧铭牌和底部战斗卷轴保留。返回主菜单不会解除已经确认的位置；手动重置战斗或任意一方死亡后，回到地图部署，允许重新选图和摆放。
### 每回合移动

玩家每回合独立拥有 **30 尺移动力**，不消耗动作或附赠动作，可在攻击之间多次拖动玩家棋子。木桩不能在战斗中拖动。

每次有效拖放按移动前后的格心直线距离扣除移动力，使用整数尺距离规则，逐段累计；往回走也扣除移动力。例如先移动 10 尺、再移动 15 尺，本回合剩余 5 尺。拖动鼠标的弯曲轨迹不计入路程，按每次确认的起终格计算。

拖动时显示本次移动距离、距本回合起点的距离及移动后剩余值，并高亮目标格。松手后落在目标格中心。越界、与木桩同格或超过剩余移动力时，本次移动取消，位置及额度不变；可按 Escape 取消拖动。

移动力耗尽后不能再次拖动玩家；剩余移动力不足到达其他格子时也不能移动到那些格子。投骰或配置面板打开时暂停移动。新回合恢复 30 尺，并以当时位置记录回合起点；剩余额度不累计到下回合。重置或死亡后回到部署，重新开始时恢复移动力。
### 战术转进移动与反应

战士 5 级起，每次使用附赠动作回气后获得 **独立 15 尺**战术转进额度（速度 30 尺的一半）。该额度不扣普通移动力，可在本回合任意时刻使用，回合结束不保留。地图旁提供普通移动与战术转进切换，拖放按当前模式扣费，仍需落在格心、不能超额、越界或与目标同格。普通移动和战术额度不在同一次拖放中混用，分段拖动即可分别使用。

双方均有 **1 次反应**，每次借机攻击消耗一次。玩家在下一玩家回合开始恢复；木桩在回合结束、开始自身反击时恢复。反应上限为 1，不随每次攻击或移动恢复，重置战斗时双方恢复。

目标沿移动段离开防守方的 **5 尺范围**时，弹出“使用反应攻击 / 放弃借机攻击”。此判定不要求装备近战武器；使用玩家当前武器或木桩自身配置攻击一次，不消耗动作或附赠动作，也不触发额外攻击。放弃保留反应。攻击在目标离开范围前结算，若死亡则重置战斗、不再完成原移动。

战术转进移动不触发借机攻击。普通移动若穿入并离开对方 5 尺范围，也会检查借机攻击；在范围内移动、单纯进入范围、部署拖动均不触发。判定暂停期间不能移动或执行其他操作，借机攻击照常遵守命中、暴击和玩家优势等规则。

木桩仍为固定目标，不会主动移动；玩家移动可以触发木桩的借机攻击。玩家反应资源和对怪物移动的借机攻击入口已接入，供怪物移动逻辑使用。
## 战斗界面

界面显示双方当前生命、生命上限、护甲等级、回合数、投骰结果和战斗日志。

| 操作 | 功能 |
| --- | --- |
| 攻击 | 对木桩进行一次命中判定，命中后结算武器伤害 |
| 结束回合 / 跳过剩余操作 | 放弃剩余动作与附赠动作，木桩反击一次后进入下一回合 |
| 返回主界面 | 保留当前战斗状态并返回菜单 |
| 玩家属性 | 位于左侧玩家角色卡，编辑六项玩家属性 |
| 玩家武器 | 位于左侧玩家角色卡，实时选择武器 |
| 怪物伤害更改 | 位于右侧怪物角色卡，编辑反击伤害骰和固定加值 |
| 怪物属性 | 位于右侧怪物角色卡，编辑怪物属性、最大 HP、护甲和熟练 |
| 玩家职业 | 选择初始职业并配置各职业等级 |
| 重置战斗 | 双方回满、恢复特性与行动次数，允许重新编辑配置 |

配置面板从所属角色卡旁侧展开，右上角有关闭按钮；面板打开时不能攻击、结束回合或返回菜单，关闭后恢复操作。属性、职业、怪物伤害配置点击“应用”后生效，非法输入不会覆盖已应用的配置。武器点击后立即切换。

每回合基础额度为 1 个动作和 1 个附赠动作。开始一个攻击动作时消耗动作，无论命中、未命中或伤害为 0 都不返还；额外攻击特性允许同一动作继续攻击，逐次点击结算。攻击动作未完成时不能切换武器。可随时结束回合，放弃剩余动作、附赠动作和额外攻击次数。木桩反击后刷新回合额度；死亡重置时也刷新。

首次有效移动、攻击、回气、动作如潮或结束回合后，双方属性、职业、HP、护甲、熟练与怪物伤害配置锁定，只允许查看。武器可在攻击动作完成后切换。右上角“重置战斗”保留已应用配置，双方回满、回合归 1、恢复行动及特性次数并解除配置锁定。返回菜单不重置战斗。投骰或侧边面板打开期间不能进行战斗操作。

## 命中与暴击

双方攻击均先投一面二十面骰（1d20）：

| 骰值 | 结果 |
| --- | --- |
| 自然 1 | 无论目标护甲是多少，必定未命中 |
| 自然 20 | 无论目标护甲是多少，必定命中并暴击 |
| 2～19 | 命中总值大于等于目标护甲等级时命中 |

未命中不投伤害骰，不扣除目标生命。暴击将伤害骰数量翻倍，增加的骰子独立投掷；力量修正和固定加值仅计算一次。最终伤害最低为 0。

玩家攻击展示 D20 和武器伤害骰的滚动过程；双方日志显示命中判定和结算结果。玩家命中总值 = D20 + 熟练加值 + 武器属性修正；怪物命中总值 = D20 + 手动熟练加值，不加入力量修正。玩家熟练加值按总等级计算：1～4 级 +2、5～8 级 +3、9～12 级 +4、13～16 级 +5、17～20 级 +6。自然 1 和自然 20 仍按原始骰值判断。

属性修正值计算方式：

```text
属性修正 = floor((属性值 - 10) / 2)
```

`floor` 表示向下取整。例如属性 3 的修正为 -4，9 为 -1，10 为 0，20 为 +5。力量用于武器伤害，体质用于生命上限；其余属性暂不参与战斗计算。玩家护甲等级固定为整数 **10**。

### 近战武器

标记为近战武器的武器自带近战武器词条，攻击距离为 **5 尺以内（含 5 尺）**，武器选择面板显示词条和范围。玩家动作攻击、额外攻击的每次攻击及轻型附赠攻击，均在投骰及扣除额度前检查当前双方距离。超过 5 尺时按钮显示无法进行攻击，不消耗动作、附赠动作、剩余攻击次数或待用优势；移动至范围内后恢复可用。按当前距离规则，横竖相邻可攻击，斜向相邻为 7 尺，不在 5 尺范围内。
### 远程武器与劣势

长弓伤害为 1d8 + 力量调整值，射程属性显示 **150/600尺**。没有灵巧词条的武器不能使用敏捷，长弓也遵守此规则。

目标在 150 尺以内（含）时正常攻击；超过 150 尺但不超过 600 尺时具有劣势，命中检定投两面 D20 取较低值，再加熟练和属性调整；超过 600 尺无法攻击且不消耗额度。暴击伤害为 2d8 + 力量调整值。

### 轻型词条与附赠攻击

短棒、匕首、手斧、轻锤、镰刀、弯刀、短剑和手弩自带轻型词条，武器选择界面显示词条，无需手动开启。装备轻型武器后，可点击“轻型攻击（附赠动作）”消耗本回合的附赠动作，独立攻击一次，无需先进行动作攻击。

轻型攻击不消耗动作，不触发或消耗战士额外攻击次数，与回气共用附赠动作额度；即使未命中也会消耗该额度。命中熟练、属性调整、灵巧、暴击和究明攻击的优势规则均正常生效。进行中的攻击动作仍保持武器锁定，不能通过附赠攻击中途换武器。轻型不自动赋予灵巧，两种词条分别判断。
## 职业、等级与生命上限

支持多职业组合。默认初始职业为战士，战士 **1 级**，其他职业均为 **0 级**。

- 各职业等级必须为 **0～20 的整数**。
- 所有职业等级之和必须为 **1～20**。
- 选作初始职业的职业必须至少 **1 级**。
- 在职业列表中点击职业按钮选择初始职业，填写等级后点击“应用”。列表支持滚动。
- 职业用于计算生命上限；战士还按战士自身等级解锁下列特性，其他职业暂无额外能力。

设体质修正为 C，各职业的生命参数如下：

| 职业 | 初始职业首级生命 | 后续每级生命 |
| --- | --- | --- |
| 战士、游侠 | 10 + C | 6 + C |
| 法师、术士 | 6 + C | 4 + C |
| 契术师、吟游诗人、牧师、游荡者、武僧、圣武士 | 8 + C | 5 + C |
| 野蛮人 | 12 + C | 7 + C |

单职业生命上限：

```text
生命上限 = (后续每级基础生命 + C) × (职业等级 - 1) + 首级基础生命 + C
```

多职业生命上限：先取初始职业的首级生命，再按各职业实际等级累计后续生命；初始职业的等级减去已计入的 1 级，其他职业等级全部计入后续生命。

例如体质 10、战士作为初始职业、战士 2 级和法师 1 级，生命上限为 `10 + 6 + 4 = 20`。默认角色生命为 **10/10**。

## 战士特性

特性按战士职业等级解锁，不按总等级解锁，支持多职业组合。

| 战士等级 | 特性 | 规则 |
| --- | --- | --- |
| 1 | 回气 | 消耗附赠动作，恢复 1d10 + 战士等级的生命，最多回到上限，每场可用 2 次 |
| 2 | 动作如潮 | 不消耗动作或附赠动作，只消耗特性次数；本回合额外获得 1 个动作，每场 1 次；17 级起每场 2 次，同回合最多用一次 |
| 5 | 战术转进 | 每次以附赠动作回气后，获得独立的半速度移动额度（当前 15 尺），本回合任意时刻可用，不引发借机攻击 |
| 5 | 额外攻击 | 每个攻击动作包含 2 次攻击；11 级为 3 次，20 级为 4 次，逐次点击，不自动连续结算 |
| 13 | 究明攻击 | 任意一次攻击未命中后，下次攻击获得优势，可跨回合保留；使用后消失，若再次失手则再次获得 |

优势攻击独立投掷两面 D20，取较高骰值，再加熟练与属性修正。自然 1、自然 20 判定也使用取高后的骰值。额外攻击期间锁定该动作的武器；额外攻击次数不会跨回合保留。动作如潮提供的动作同样享受额外攻击。

回气和动作如潮提供独立按钮，界面显示剩余使用次数、动作额度及待生效的优势。任意一方死亡或手动重置战斗后，恢复每场特性次数、清除待用优势和额外攻击，并允许重新编辑配置。

## 法术与施法

玩家铭牌的法术书签打开法术列表，鼠标悬停法术显示简概。法师或术士至少 1 级即可使用酸液飞溅，暂不提供额外学习流程；同时拥有两者等级时可选择施法职业。法师使用智力、术士使用魅力。

| 酸液飞溅（Acid Splash） | 配置 |
| --- | --- |
| 学派 / 环阶 | 塑能 / 戏法 |
| 可用职业 | 法师、术士 |
| 施法时间 | 1 动作 |
| 成分 | V 声音、S 姿势 |
| 持续时间 | 立即，非专注 |
| 射程 / 范围 | 60 尺 / 5 尺半径球状 |
| 伤害类型 | 强酸 |
| 基础伤害 | 1d6；总等级 5 / 11 / 17 时提升至 2d6 / 3d6 / 4d6 |

点击法术后，在地图上点击 60 尺内的格心选择爆发中心，范围高亮并列出范围内目标，再确认施法。可取消选点，不消耗动作；确认后消耗一个动作，范围内无目标也视为已施法。部署阶段只能查看法术，开始战斗后才能施放。

玩家自身不包含在伤害目标中。木桩若在范围内，进行 D20 + 敏捷调整值的豁免，与 `8 + 玩家熟练加值 + 所选职业施法属性调整值` 对抗。大于等于 DC 成功，不受伤害；失败承受全部骰值合计的强酸伤害。豁免不应用武器攻击的自然 1、自然 20 或优势规则，法术伤害不附加力量或施法属性调整值，不触发战士额外攻击。
## 怪物属性与反击伤害

木桩默认生命为 **1000/1000**，护甲等级为 **10**。

| 配置项 | 默认值 | 输入限制 |
| --- | --- | --- |
| 力量、敏捷、体质、感知、智力、魅力 | 各 10 | 3～20 的整数 |
| 最大 HP | 1000 | 至少为 1 的整数 |
| 护甲等级 | 10 | 5～30 的整数 |
| D4、D6、D8、D10、D12 数量 | 各 0 | 非负整数，配置数量之和不超过 10000 |
| 固定加值 | 0 | 整数，允许负数 |
| 怪物熟练加值 | 0 | 整数，允许负数，无额外等级范围限制；在怪物属性中应用 |

怪物六项属性用于录入，暂不提供命中或伤害修正。怪物反击仅在结束回合时触发，命中后按以下公式结算：

```text
普通伤害 = n4d4 + n6d6 + n8d8 + n10d10 + n12d12 + 固定加值
暴击伤害 = (2×n4)d4 + (2×n6)d6 + (2×n8)d8 + (2×n10)d10 + (2×n12)d12 + 固定加值
```

默认反击伤害为 0。负伤害按 0 结算，不会治疗玩家。伤害日志显示各类骰子的数量、小计、固定加值和最终伤害。

## 血量恢复与输入规则

- 普通回合结束时双方不回血。
- 任意一方生命降至 0 时，记录死亡结果，双方同时恢复至各自生命上限，回合重置为 1。
- 修改体质或职业导致玩家生命上限改变时，玩家当前生命同步回满至新上限。
- 修改怪物最大 HP 时，怪物当前生命同步回满至新上限。
- 最大 HP 未实际变化时不回血；仅修改护甲也不回血。
- 游戏属性、等级、骰子数量、加值、护甲、HP 和伤害均使用整数；数值输入框不接受小数。
- 音量设置保存到本机；战斗与角色配置保留在本次运行中，未提供战斗存档功能。
