# 转生术接入记录

战后施法已接通玩家、木桩和救援者。种族本身尚未完成的特性仍保留待接入状态，不因转生而自动生效。

## 已确认的项目规则

- 旧遗体独立保留，可以继续搬运；装备留在旧遗体处，须回收。旧躯体只作为遗留物体，所有复活入口只针对角色的现身体。
- 玩家选择旧遗体旁5尺内的合法位置生成新身体，新旧身体不能重叠。
- 新身体沿用旧身体的体重，恢复至新身体的HP上限。
- 怪物种族特性等级使用独立的1～20级整数，默认1；熟练加值沿用手填值，使用次数最低0。

## 已接入的依赖

独立旧躯体拥有单独编号、位置、占地和重量快照，多次转生的旧身体可同时保存。地图查询会检查新身体与旧遗体、其他生物、旧形态恢复空间的冲突；预览不会改变棋子或生成遗体。转生位置查询限5尺。

救援者的搬运目标从固定的玩家／木桩扩展为独立遗体编号。肩扛不额外占地，拖行保留原占地；移动、放下、失能时的最近合法放置及必要挪位沿用原规则。落地和拖行旧遗体接入半掩护，肩扛不重复提供掩护。

武器保留唯一库存归属，单双手长剑仍共用一件；回收不会生成复制品。护甲、盾牌和其他装备按实际重量转移到背包，回收不改变穿戴与AC，战斗中穿戴仍按既有限制锁定。物件交互、空手、距离、水下与负重均需满足；失败不消耗交互，也不移动装备。回收后同步减少遗体及搬运者的负重。

施法前验证类人生物、死亡10天内、自愿、施法资格、场内倒地状态和合法生成位置，失败不推进时间。合法施法推进1小时，展示1d10种族结果，随后填写该种族的可选项并在地图选择新位置。角色保留原六项属性、等级与已消耗的休息限定资源；移除旧种族来源、应用当前已实现的新种族特性。新身体沿用原体重并恢复至新上限，装备留旧体，复活后保留战后阶段。

救援者的六项属性默认10，均为3～20整数；种族等级1～20、默认1，熟练加值默认0、允许负数，次数最低0。新增附赠动作和反应，每回合各一次，跟随救援者自己的回合恢复；已接入兽人疾走、矮人石中精妙，以及适用的种族HP、抗性、熟练和强壮体格。短休、长休资源独立记录，精灵长休4小时，其余8小时，每24小时只取得一次长休收益。救援者的血统法术施放与尚未完成的其他种族主动特性，仍按各模块后续进度接入。
