# 转生术接入记录

正式施法入口仍待接入，法术目录继续保持“待接入”。种族本身尚未完成的特性也不会因此标记为已完成。

## 已确认的项目规则

- 旧遗体独立保留，可以继续搬运；装备留在旧遗体处，须回收。
- 玩家选择旧遗体旁5尺内的合法位置生成新身体，新旧身体不能重叠。
- 新身体沿用旧身体的体重，恢复至新身体的HP上限。
- 怪物种族特性等级使用独立的1～20级整数，默认1；熟练加值沿用手填值，使用次数最低0。

## 已接入的依赖

独立旧躯体拥有单独编号、位置、占地和重量快照，多次转生的旧身体可同时保存。地图查询会检查新身体与旧遗体、其他生物、旧形态恢复空间的冲突；预览不会改变棋子或生成遗体。转生位置查询限5尺。

救援者的搬运目标从固定的玩家／木桩扩展为独立遗体编号。肩扛不额外占地，拖行保留原占地；移动、放下、失能时的最近合法放置及必要挪位沿用原规则。落地和拖行旧遗体接入半掩护，肩扛不重复提供掩护。

武器保留唯一库存归属，单双手长剑仍共用一件；回收不会生成复制品。护甲、盾牌和其他装备按实际重量转移到背包，回收不改变穿戴与AC，战斗中穿戴仍按既有限制锁定。物件交互、空手、距离、水下与负重均需满足；失败不消耗交互，也不移动装备。回收后同步减少遗体及搬运者的负重。

纯规则检查涵盖类人生物限制、10天死亡期限包含1小时施法、新身体保留体重及回满HP。当前只完成这些规则与运行时依赖，尚未开放实际转生施法。
