# 2024种族系统

玩家属性与怪物属性中可进入种族设置。包含阿斯莫、龙裔、矮人、精灵、侏儒、歌利亚、半身人、人类、兽人、提夫林；也可保留无种族特性的自定义配置。首次战斗操作后锁定。木桩及生前资料各自保存独立种族特性等级（1～20，默认1）；玩家使用职业总等级。木桩种族特性沿用手填熟练加值，次数最低0。

## 已接入的被动结算

- 体型、种族基础移动力、血统选择、黑暗视觉距离。木桩选择种族时填入基础体型、类型与速度，仍可在原怪物配置中自定义数值。
- 阿斯莫的死灵／光耀抗性、龙裔的祖先类型抗性、矮人毒素抗性、提夫林的血统抗性。与同类型抗性不叠加。
- 矮人每级1HP、人类选择健壮专长时每级2HP；配置修改引起上限变化时同步回满，恢复生前资料时不提前治疗尸体。
- 精灵无需睡眠及正常精灵形态的4小时冥想长休、侏儒智力／感知／魅力豁免优势、矮人避免／结束中毒豁免优势、半身人避免／结束恐慌豁免优势。非精灵及兽形长休仍为8小时；每日长休收益间隔保持24小时，固定外部施法者仍为8小时。
- 人类可选技能、精灵敏锐感官技能、人类熟习的3项技能／工具选择。熟练与职业／背景分开保存，移除种族只移除对应来源；专精在仍具有熟练时生效。可选熟练重复时须在原列表内另选，不能额外补选。
- 歌利亚强壮体格在装备携带校验中按大一级体型；它不增加地图实际占地。
- 半身人穿行可经过体型比自身更大的生物占格；普通移动也允许经过盟友、失能生物、微型生物或相差至少两级体型的生物。兽形中按当前形态判断，不保留原种族穿行。经过非微型敌人的完整占地按困难地形计费，与法术困难地形不叠加。
- 怪物生前资料深复制种族及其选择，完全复生术恢复对应配置。

主动移动的终点仍须空闲。穿行途中因倒地、失能或伤害被迫停下时保留共占位置，只扣实际路程；双方仍可从共占位置移出。自己的回合结束时仍与活体生物共占，除非自身是微型或体型大于所有共占者，否则倒地；已有倒地状态不会因此解除。骑手与坐骑的正常共占不触发此判定，遗体继续按既有占地规则阻挡移动。变形恢复占地的安全限制仍须满足。

陆地统一按石质表面、水域不算；地图查询可区分接触石质表面与相连石面，不新增地面编辑器。石中精妙据此定位接触相连石面的目标，范围60尺、持续10分钟；不提供视觉，不消除不可见攻击影响。水域或骑乘、吞咽、肩扛状态不视为本人接触石面。

## 已接入的主动使用

玩家铭牌的“种族”书签提供主动特性。阿斯莫治愈之手消耗1个魔法动作，接触一个生物，恢复熟练加值数量的d4生命，每长休1次；不施放法术，不消耗附赠动作或法术位，不触发生命羁绊。玩家可在战后使用，救援者可在自己的行动阶段使用；木桩受伤且熟练加值为正时按配置优先级治疗自身。动作资源与动作法术／自定义攻击共用，不能重复消费。

兽人肾上腺素激增执行疾走、给予熟练加值数量的临时HP，次数等于熟练加值，短休或长休恢复；临时HP保留较高值。矮人石中精妙按熟练加值取得使用次数，长休恢复。兽形中原种族的这些身体特性不可使用，已有持续时间继续流逝。

龙裔吐息可替换自身攻击动作中的一次攻击，每个攻击动作至多替换一次；战士额外攻击保留其余次数，动作如潮的新攻击动作可再次替换，仍须有长休次数。可选15尺锥形或30尺长、5尺宽线形，按祖先类型造成1d10伤害，在角色总等级5／11／17时增至2／3／4d10；木桩与救援者使用独立种族等级。敏捷豁免DC为8＋体质调整值＋熟练加值，成功减半。次数为熟练加值，最低0，长休恢复；不施放法术，不进行攻击检定，不暴击，也不消耗究明攻击优势。

吐息可在源点边缘选择起点并点击地图瞄准，格心落在范围内才生效，多格目标最多结算一次。玩家与救援者预览全部覆盖目标后确认，木桩按已有特性优先级选择覆盖最多敌人的合法模板，不能使用时保留动作回退。包含生物半掩护、失能自动失败、伤害抗性、水下火焰抗性及受伤专注结算；同类抗性不叠加。吞咽内部不能波及外界。飞行仍暂缓。

其他已实现特性按各自的附赠动作消耗结算。怪物种族配置及生前资料可选择“种族特性优先／常规法术优先／禁用自动使用”。木桩自动使用可用特性，并与附赠动作法术共用每回合一次的额度；动作法术和自定义攻击不占附赠动作。无法使用的循环法术仍按既有规则推进列表并回退自定义攻击。石中精妙正在持续时自动跳过重复激活，玩家仍可花费次数手动刷新。木桩战后增加1小时短休入口。

## 玩家血统法术

种族授予的法术按总等级自动出现在法术书的可用来源中，使用所选智力／感知／魅力施法；阿斯莫光亮术固定魅力。高等精灵可选法师戏法，长休后可更换一次。已实现的同名法术复用完整战斗结算，包含酸液飞溅的范围与双方豁免。

有环阶的种族法术分别记录免费次数，默认每长休一次；森林侏儒动物交谈术按熟练加值计算。免费施法固定基础环阶，在消耗行动时扣次，被反制仍扣次；也可选择项目现阶段不限的法术位路线。长休和重置恢复免费次数，短休不恢复。

尚未实现效果的血统法术仍标为待接入，不因获得学习资格而开放施法。当前这套种族施法来源用于玩家；木桩继续使用已有的循环法术配置，自动血统施法尚待接入。

## 继续接入中的范围

除以上特性外的主动动作、反应、巨人先祖能力、变身、英雄激励、幸运重投、坚韧不屈、天然善匿、未完成的血统法术效果及其他起源专长尚未因选择种族自动生效。界面明确显示待接入范围。飞行沿用暂缓决定；环境物件和岩侏儒装置沿用环境系统边界。转生术已接入复生与新身体流程，但不把选中种族等同于完成其全部特性。救援者也具备独立种族资料与资源，仍按上述已接入范围结算。

数据校验：`Tools/Test-SpeciesIntegration.ps1`覆盖种族／血统、独立熟练、HP、抗性、豁免优势、负重、精灵冥想、主动特性次数／休息、附赠动作优先级、移动额度及生前资料深复制；不代表已完成尚待接入的主动特性或转生术。

`Tools/Test-BreathWeaponIntegration.ps1`覆盖锥形／线形格心覆盖、体型、等级与类型、极端DC、短长休次数、额外攻击替换、动作如潮及木桩模板选择。

`Tools/Test-CreatureTransitIntegration.ps1`覆盖穿行许可、主动终点阻挡、敌方困难地形、分段扣费、被迫共占与体型豁免，并回归水域、地形、骑乘和救援移动。

怪物自动行动现在在怪物法术面板统一排序和启停（种族主动特性、法术循环、龙息术喷吐、自定义攻击），取代原先仅按种族／常规法术先后的选择；各种行动仍共享对应的动作或附赠动作额度。生前资料独立保存该配置。
