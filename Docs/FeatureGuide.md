# 功能说明

基于 **Unity / C#** 的 D&D 战斗数值模拟器。玩家可配置角色、职业和武器，在网格训练场中与木桩战斗，查看命中、伤害、法术及状态的逐步结算。

界面采用暖色酒馆桌面、金属角色铭牌、羊皮纸战斗卷轴和立体骰子。规则以 **D&D 2024** 为参考，并包含训练场专用裁定；当前不是完整的 2024 规则引擎。

## 快速开始

1. 使用 **Unity 2022.3.62f3c1** 打开仓库根目录。
2. 打开 `Assets/Scenes/Main.unity`，点击 **Play**。
3. 选择“进入战斗”，选定地图并拖动部署玩家与木桩。
4. 在首次有效战斗操作前配置属性、职业、技能及怪物数据。
5. 点击“开始战斗”锁定部署，执行攻击、施法或移动，再结束回合。

Windows 独立程序可通过 **File > Build Settings > Windows > Build And Run** 构建。“退出游戏”在独立程序中关闭程序，在编辑器中停止 Play。

本机编辑器路径：`C:\Program Files\Unity 2022.3.62f3c1\Editor\Unity.exe`。该路径仅为本机安装位置，项目要求的版本以 `ProjectSettings/ProjectVersion.txt` 为准。

## 界面与操作

主菜单提供进入战斗、声音设置和退出入口，并支持战斗外休息。返回主菜单保留当前战斗，手动重置才会重新部署。

战斗界面中央是地图与投骰区域，两侧为角色铭牌，底部卷轴可滚动查看本次运行的战斗记录。玩家使用金铜铭牌，怪物使用旧铁铭牌；生命宝石在受伤和治疗时分别闪红、闪绿，玩家纹章按初始职业显示代表物件。布局按1600×900设计，随窗口等比缩放。

| 入口 | 用途 |
| --- | --- |
| 玩家属性／武器／职业 | 编辑角色配置、选择武器、配置多职业和子职业 |
| 技能／法术／职业特性 | 配置与执行检定、浏览或施放法术、查看特性状态 |
| 怪物属性／伤害／技能／生前 | 配置当前怪物、混合伤害、技能熟练及独立生前资料 |
| 攻击／轻型攻击／战士能力 | 执行对应动作或特性，显示剩余资源 |
| 结束回合 | 放弃剩余操作，进入木桩行动和下一回合 |
| 重置战斗 | 保留基础配置，恢复生命与资源、清除效果并重新部署 |

侧边面板从角色卡旁展开，右上角关闭。面板打开、投骰或等待反应选择时，相关战斗操作暂停。配置点击应用后生效，非法输入不覆盖原值；武器点击后切换，但进行中的攻击动作锁定武器。

首次有效战斗操作后，属性、职业、怪物伤害等基础配置锁定。返回菜单不会解除锁定；重置战斗后可重新编辑。

### 声音与投骰

- 背景音乐和投骰音效由程序合成，无需外部音频素材。
- 音乐、音效分别以整数百分比调整；音量和投骰表现保存在本机。
- 立体模式提供标准／快速动画，简洁模式直接显示骰值与计算。
- 每次投骰结束均展示结果 **2秒**，再进入后续骰子或结算。
- 同类怪物伤害骰超过两个时，立体展示前两骰，卷轴记录完整合计。

## 地图、移动与反应

| 地图 | 网格 | 边长 |
| --- | --- | --- |
| 小 | 10×10 | 50尺 |
| 中 | 15×15 | 75尺 |
| 大 | 20×20 | 100尺 |

每格5尺。部署时双方完整占地必须在地图内且不重叠；大型占2×2格、巨型3×3格、超巨型当前采用4×4格。多格单位按占地左上格记录位置，图形中心可落在格线交点。

距离取双方最近占用格中心的直线距离，并结算为整数尺：横竖相邻5尺、斜向相邻7尺。范围法术按完整占地判断；当前没有高度、飞行或墙壁编辑系统。

### 移动与回合资源

每回合基础资源为 **1个动作、1个附赠动作、30尺普通移动力、1次反应**。速度可受形态和法术影响，剩余资源不跨回合累计。

玩家通过分段拖动移动，不消耗动作或附赠动作。每段按确认的起终位置扣费，往返也计入累计路程，鼠标拖动的弯曲轨迹不计费。拖动时显示本段消耗、距回合起点距离和剩余移动力；越界、占地冲突或超额时取消，按 Escape 也可取消。

木桩在自身回合恢复移动与反应，自动追近玩家：能进入攻击范围时走到最近可攻击位置，否则尽量缩短距离；仍在范围外则跳过攻击。战斗中不能手动拖动木桩。

### 借机攻击

可见目标沿移动段离开防守方攻击范围时，弹出是否消耗反应攻击一次的选择；仅进入范围或在范围内移动不触发。判定使用完整占地及离开范围的时点，木桩采用配置的攻击距离，玩家当前借机范围为5尺。

借机攻击不消耗动作或附赠动作，不触发额外攻击；依项目裁定，不要求装备近战武器。放弃保留反应。目标死亡时终止剩余移动并保留现场。战术转进、传送和强制位移不触发借机攻击。反应在角色下个自身回合开始时恢复，上限1次。

## 命中、伤害与生命

```text
属性调整值 = floor((属性值 - 10) / 2)
玩家武器命中 = 1d20 + 熟练加值 + 武器属性调整值 + 有效效果修正
木桩命中 = 1d20 + 手动熟练加值 + 有效效果修正
```

玩家熟练加值按总等级计算：1～4级+2、5～8级+3、9～12级+4、13～16级+5、17～20级+6。木桩命中不自动加入力量调整值。

- 攻击自然1必失，自然20必命中并暴击；其余结果达到目标护甲等级即命中。水下远程武器超过通常射程的必失限制单独生效。
- 暴击翻倍伤害骰数量，固定加值和属性调整值不翻倍；未命中不投伤害骰。
- 优势投两面D20取高，劣势取低；来源不叠加，任意优势与任意劣势互相抵消。
- 豁免与一般属性／技能检定不套用攻击的自然1／20规则；死亡豁免有独立规则。
- 伤害按类型合并，负固定加值只抵扣同类型，各类最低0。例如6火焰＋4钝击－8钝击，剩6火焰。
- 抗性按类型减半并向下取整，专注检定使用实际承受伤害。免疫／易伤有分类计算基础，未提供完整角色配置流程。
- 临时生命不与已有临时生命相加。变形术提供临时生命时，已有数值由玩家选择保留或替换。

普通回合结束不回血。配置修改使最大HP实际改变时，当前HP回满至新上限；上限不变或只改护甲不会回血。临时法术按自身规则处理，例如援助术只增加规定的当前HP和上限，到期扣回实际增加值，当前HP最低0。

## 玩家配置与武器

六项属性为力量、敏捷、体质、感知、智力、魅力，默认各10，仅接受 **3～20的整数**。属性、等级、伤害、HP、护甲和普通加值均以整数输入和结算；标准CR分数是单独的选项，不开放任意小数。

玩家基础护甲为10，可受形态和法术影响。普通近战武器用力量，普通远程武器用敏捷；**灵巧**自动取力量／敏捷调整值较高者，相等时用力量，无需玩家选择。

射程以“通常／最远”表示；通常射程内正常攻击，超过通常射程但不超过最远射程时具有劣势，超过最远射程无法攻击。

### 轻型附赠攻击

本回合先使用另一轻型武器进行攻击动作后，可消耗附赠动作再攻击一次。该次攻击不加入正属性调整值，负调整仍扣除；不触发或消耗额外攻击次数，与回气共用附赠动作。

当前按不同武器条目辨认前置条件，尚无左右手装备及同类武器实例。进行中的攻击动作仍锁定原武器。

## 职业、生命与特性

支持战士、法师、游侠、术士、契术师、吟游诗人、牧师、游荡者、武僧、圣武士、野蛮人、德鲁伊。默认初始职业为战士1级，其余0级。

各职业等级为0～20整数，总等级必须为1～20，初始职业至少1级。每个职业达到自身3级时须选择一个子职业；48项子职业目前保存选择，不自动结算其具体能力。

设体质调整值为C：

| 职业 | 初始职业首级HP | 后续每级HP | 生命骰 |
| --- | --- | --- | --- |
| 战士、游侠、圣武士 | 10＋C | 6＋C | d10 |
| 法师、术士 | 6＋C | 4＋C | d6 |
| 契术师、吟游诗人、牧师、游荡者、武僧、德鲁伊 | 8＋C | 5＋C | d8 |
| 野蛮人 | 12＋C | 7＋C | d12 |

多职业HP先取初始职业首级，再累计各职业剩余等级的后续HP。例如体质10、初始战士，战士2／法师1时，最大HP为 `10 + 6 + 4 = 20`。

### 战士能力

| 战士等级 | 特性 | 结算 |
| --- | --- | --- |
| 1 | 回气 | 附赠动作，恢复1d10＋战士等级，截止生命上限；1～3级2次、4～9级3次、10级起4次 |
| 2 | 动作如潮 | 不消耗动作／附赠动作，本回合增加1个不可施法动作；每次短／长休后1次，17级起2次，同回合最多用1次 |
| 2 | 战术头脑 | 属性／技能检定失败后可选加1d10，只有转为成功才消耗1次回气，不治疗 |
| 5 | 战术转进 | 附赠动作回气后获得独立半速度移动，本回合内使用，不引发借机攻击 |
| 5 | 额外攻击 | 每个攻击动作2次攻击，11级3次、20级4次；逐次点击，中途不能换武器 |
| 13 | 究明攻击 | 攻击失手后，下次攻击具有优势，使用后消失，最迟下个玩家回合结束失效 |

### 德鲁伊荒野形态

德鲁伊2级解锁，变身消耗附赠动作与1次使用，主动复原消耗附赠动作。基础2次，6级3次、17级4次；短休恢复1次，长休恢复全部。2／4／8级的已知形态上限为4／6／8，基础CR上限为1/4、1/2、1。

当前可用地面形态为老鼠、蜘蛛、狼、乘用马、猫、鼬、狒狒、鹿、骡、矮种马。装备统一融入，变身期间使用野兽攻击；空间不合法时不消耗动作或次数。飞行及其他野兽动作待接入。

变形术可叠加在荒野形态上；结束后恢复仍有效的底层形态，原持续时间继续流逝。变大前预览并选择与原占地重叠的合法位置，移动不能使原形失去就近恢复空间。无CR且无职业等级的召唤物暂不能成为变形术目标。

## 属性、技能与工具检定

“技能”书签提供六项属性、18项技能和37种工具检定。所有手动检定消耗1个动作，DC默认10，可填写任意整数。

首次操作前选择16种背景之一，并完成职业、背景相关专长、熟练与专精选择。固定重复熟练不额外补选；可选项目重复时须在原列表内另选。背景属性提升、装备和其他未接入专长收益不会自动生效。

已接入相关职业技能授予、部分专精、万事通、可靠才能及战术头脑。技能使用合适辅助工具且二者均熟练时可获优势，熟练加值不重复计算。脆弱诅咒影响指定属性检定；猎人印记可对明确的寻找目标检定提供优势。怪物技能可配置无熟练／熟练／专精，当前不提供怪物手动检定。

## 法术与视觉

法术书支持中英文搜索、职业筛选、悬停简概及实现状态显示。法术集以可读取的2024法术资料为范围；删除奇械师可用职业、仪式选项与材料成分，V为声音、S为姿势。

法术位资源管理及完整学习／准备数量限制尚未启用。可用法术按职业资格施放，升环在详情中选择；学习条目和待接入条目不会因此获得战斗效果。

已接入结算涵盖伤害与治疗、范围豁免、专注、标记、临时生命、护甲和抗性、移动、感官、隐形、变形及部分复活效果。常见操作包括：

- 酸液飞溅：60尺内选点，5尺半径，范围包含自身，各目标独立敏捷豁免、共享伤害骰；总等级5／11／17时强化。
- 魔法飞弹：逐枚分配目标，每枚独立投1d4再加1。
- 护盾术：先仅提示攻击命中，选择是否使用反应后才公开命中数值；与镜像术同时触发时由玩家选顺序。
- 雷鸣波：范围预览、豁免与推离；遇边界或占地冲突停在最后合法位置，无额外碰撞伤害。
- 援助术：按规定增加生命及上限，结束时按项目规则扣回，而非配置式回满。
- 术法迸发：选择伤害类型并结算追加骰；项目暴击裁定同时翻倍基础骰、触发的追加骰及追加上限。

需要专注的法术同一施法者只能维持一个。受伤时进行体质豁免，DC为10与实际伤害一半向下取整的较大值，最高30；失能、死亡或到期结束。部分法术仅接入已有战斗状态，具体限制见法术简概和专题文档。

## 倒地、战后、复活与休息

玩家HP归零后昏迷，不能行动、移动或使用反应，并在自身回合开始进行死亡豁免：达到10累计成功，未达到10累计失败；自然1累计两次失败，自然20恢复1HP。三次成功稳定，三次失败死亡。倒地受伤增加失败，暴击增加两次；溢出伤害达到生命上限会立即死亡。木桩HP归零直接死亡。

战斗结束保留现场，不自动回满。战后可接近遗体并施放已接入的回生术、死者复活、复生术、遗体防腐、转生术和完全复生术；玩家死亡时可使用简化外部施法者救援。施法推进世界时间，检查死亡期限与自愿条件。

复活后手动点击“继续战斗”开始新回合，仅刷新回合资源，保留当前HP、已用职业次数和仍有效的法术。完全复生术可将亡灵木桩恢复为独立的生前资料，必须能在原位置容纳完整占地，否则禁止施法且不推进时间。

短休推进1小时，可使用职业生命骰治疗，恢复1次回气、全部动作如潮及已接入的短休资源。长休推进8小时，恢复生命、生命骰和已接入的长休资源，每24小时最多获得一次长休收益。活动战斗中不能休息。手动重置是训练场重开工具，不等于标准休息。

### 怪物施法

怪物卡牌的“法术”书签可在首次操作前编辑循环列表及每项环阶；每回合尝试一项，无合法目标或不能施法时改用自定义攻击，循环仍前进。动作法术替代攻击，附赠动作治疗后仍可攻击。当前支持火焰箭、圣火术、毒气喷溅、亡者丧钟、致伤术、疗伤术、治愈真言、魔法飞弹、灼热射线、枯萎术、律令死亡、酸液飞溅、火球术、粉碎音波、死亡法阵、鸣雷破、光耀祷词；其余怪物法术尚未开放。伤害法术优先最近合法敌人，治疗自身。

施法属性可选六项，默认智力；命中为手填熟练加值＋属性调整值，DC再加8，允许负熟练加值。独立施法等级默认1，范围1～20，只影响戏法强化。首次操作后锁定，重置保留列表并从第一项重新开始。生前形态具有独立法术配置。

玩家可选择消耗反应施放法术反制；怪物须先勾选具备此法术，之后满足条件时自动反制。触发要求看见60尺内正在施放有成分的法术；自定义“法术攻击”能力不会触发。原施法者体质豁免失败则法术无效，动作资源仍消耗，法术位不扣除。双方可反制对方的法术反制，均受各自一次反应限制。参考：[PHB2024法术反制](https://roll20.net/compendium/dnd5e/Spells:Counterspell?expansion=32231)。

怪物范围法术：指定点的球状范围会枚举地图内格心，排除超出施法距离或波及自身完整占地的中心，优先覆盖最多敌人；数量相同则优先更近中心，再按固定行列顺序。没有安全且能命中敌人的落点时改用自定义攻击。自身光环按怪物完整占地计算并排除自身；光耀祷词仅选可见敌人。施法前显示范围，仍可被法术反制；每个目标独立豁免，整次法术共用伤害骰，成功减半或免伤按法术结算。环境效果仍暂缓。

- **站住**：不移动、不执行动作或附赠动作，结束回合。

命令造成的行走使用本单位移动池，按水域、困难地形、占地与恢复原形空间结算，并正常触发借机攻击与区域伤害，不当作免费推离或传送。不能移动时仍消耗本次命令回合；途中失能或倒地按现有移动规则停止。玩家、木桩、召唤物及救援者接入下一回合结算；战后单位保持手动操控关闭，但仍会执行已存在的命令。木桩法术循环每一项可独立选择命令，升环优先最近合法敌人，无目标则用原有攻击。死亡／重置会移除待执行命令；同名施法最高DC优先、相同取最新，其余同回合命令不叠加。参考：[2024命令术](https://www.dndbeyond.com/spells/2618985-command)。

当前龙息术施法入口为玩家法术列表，尚未加入怪物主动施放的法术循环；玩家可以把龙息术赋予自愿的木桩，由木桩按优先级使用喷吐。参考：[2024龙息术](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions#DragonsBreath)。

### 火焰护盾

四环塑能，德鲁伊／术士／法师。动作、自身、声音与姿势，非专注持续10分钟。施法选择暖盾（寒冷抗性、火焰反伤）或寒盾（火焰抗性、寒冷反伤）；同名效果不叠加，等强度采用最新施法。

5尺内生物用近战攻击检定命中时，自动受到2d8对应类型伤害，不消耗反应，不因原攻击暴击或升环增加骰数；远程攻击和5尺外的长触及攻击不触发。命中时记录反伤，即使本次攻击耗尽黯冰狱铠的临时生命，已触发的反伤仍可结算；两者同时触发时由玩家选择顺序，各自处理伤害减免及专注。固定反伤不受伤害掷骰减值影响。

发出10尺明亮、外围10尺微光，随本体或搬运者移动；吞咽内部与其他位面视图隐藏外部照明，持续时间仍推进。非专注，不会终止其他专注；到期或重置清除。

参考：[2024火焰护盾](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions#FireShield)。

### 十字军披风

三环塑能，圣武士。动作、自身、声音，专注至多1分钟。30尺光环随玩家移动；自己与范围内受控盟友的武器或徒手命中额外1d4光耀，暴击为2d4，升环不增强。兽形自然攻击、轻型附赠攻击、借机攻击及受控召唤物攻击均可受益；法术攻击不获得此加骰。

额外光耀并入整次命中的伤害包，同类型先合计再处理伤害减免。盟友无需可见，距离使用完整占地；不同位面与吞咽内外隔离，失控亡灵不再算盟友。专注结束、失能、死亡或到期立即停止受益。

参考：[2024十字军披风](https://5echm.kagangtuya.top/topics/%E7%8E%A9%E5%AE%B6%E6%89%8B%E5%86%8C2024/%E6%B3%95%E6%9C%AF%E8%AF%A6%E8%BF%B0/3%E7%8E%AF.htm#Crusader%27s_Mantle)。

### 元素武器

三环变化，德鲁伊／圣武士／游侠。动作、接触、声音与姿势，专注至多1小时。选择5尺内可接触的非魔法实体武器，指定强酸、寒冷、火焰、闪电或雷鸣。三至四环命中＋1、额外1d4；五至六环命中＋2、额外2d4；七环以上命中＋3、额外3d4。加值只用于命中，不增加固定伤害；暴击只翻倍额外骰。

可选择现有玩家武器、木桩手持武器及亡灵持有的武器，包括合法接触的落地武器。附魔绑定物件，长剑两种握法共用；切换、掉落、转交亡灵或融入形态不单独终止附魔，只有用该物件攻击才获得加值。自然武器与焰刃不属于实体物件目标。水下武器须先潜水才能触碰，融入形态的装备不能作为新施法目标。

魔化武器也按物件记录附魔，已受魔化武器或元素武器影响的目标不能再次作为非魔法武器选择。额外骰并入整次伤害包，再结算衰弱射线及伤害减免；专注结束、到期或重置清除元素武器。

参考：[2024元素武器](https://5echm.kagangtuya.top/topics/%E7%8E%A9%E5%AE%B6%E6%89%8B%E5%86%8C2024/%E6%B3%95%E6%9C%AF%E8%AF%A6%E8%BF%B0/3%E7%8E%AF.htm#Elemental_Weapon)。

### 咒唤兽群

三环咒法，德鲁伊／游侠。动作、60尺、声音与姿势，专注至多10分钟。在可见且未被占据的2×2空间创造大型幽灵兽群，可选狼、蛇或鸟的外观，规则相同。兽群不属于实体生物，不阻挡通行，也不引发借机攻击；出现时不立即造成伤害。施法者在兽群5尺内时，力量豁免具有优势。

兽群移动至生物10尺内、生物进入该范围内的新空间（包括范围内继续移动）或在其中结束回合时，玩家可选择是否令可见目标进行敏捷豁免，失败受到3d10挥砍，每升环增加1d10，成功无伤害。同一生物每个行动回合至多进行一次该豁免；跳过不消耗这次资格。掩护从兽群完整占地计算，额外伤害减值及抗性沿用现有结算。

玩家本回合实际移动后，可从法术书控制兽群。按已确认的项目规则，兽群每个玩家回合累计最多移动30尺，可分多次使用，不消耗动作或附赠动作，不累积到下回合；普通、战术与跳跃移动共用该额度。移动沿途逐格触发，落点须未被占据且可见；控制不重新施法、不刷新持续时间。兽群留在原位面，吞咽内外隔离；到期、专注结束或重置清除。与其他持续地形同时触发时可选择结算先后。

参考：[2024咒唤兽群](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions#ConjureAnimals)。

### 荆棘之雨

一环咒法，游侠。自己的回合远程武器命中后，立即选择是否用附赠动作施放，声音、非专注、即时。每次施放可选择先结算原武器伤害或先结算法术伤害。选择环阶后，原目标及其周围5尺内所有生物进行敏捷豁免，每环1d10穿刺，成功半伤；这组范围骰不继承原攻击的暴击，不触发额外武器命中效果。

范围包含附近玩家和盟友，不要求看见所有受波及目标；使用命中时记录的目标完整占地判断范围与掩护。即使原目标先被击杀，仍从原命中处结算其他目标；已经死亡的生物不重复接受伤害。吞咽内部的爆发只影响容纳者与体内目标，不波及外部。武器伤害与法术伤害分别处理减免，成功豁免先减半再应用抗性。

施放会检查声音、护甲训练、施法资格和附赠动作；可被法术反制，反制后原武器命中照常结算。不能直接从法术书施放；法术位沿用当前不限的项目规则。

参考：[2024荆棘之雨](https://5echm.kagangtuya.top/topics/%E7%8E%A9%E5%AE%B6%E6%89%8B%E5%86%8C2024/%E6%B3%95%E6%9C%AF%E8%AF%A6%E8%BF%B0/1%E7%8E%AF.htm#Hail_of_Thorns)。

### 召雷术

三环咒法，德鲁伊。动作、120尺、声音与姿势，专注至多10分钟。选择可见的云团投影中心，再选择云下可见落雷点；云团半径60尺，投影可超出棋盘边缘。首次施法立即落雷，落雷点5尺内所有生物进行敏捷豁免，三环3d10闪电，每升环增加1d10，成功半伤。范围包含自己与盟友，不要求看见全部受波及目标。

准备阶段在玩家属性的光照配置处可设置“室外风暴”，默认关闭，首次操作后锁定。施法时若开关启用，整次召雷术额外增加1d10，后续落雷保留该快照。已存在云团可用魔法动作再次落雷，不需要重新施法或发声，不消耗附赠动作，不刷新时间；只要有额外魔法动作，同一回合也可再次使用。施法者移动不改变云团位置，后续落雷只需在固定云下可见，不受施法者与云心的持续距离限制。

云团留在原位面，其他位面与吞咽内部不能控制；恢复可控制条件后可在剩余时间内继续使用。普通施法仍检查形态、护甲与声音，后续控制不属于重新施法；持续时间结束、失去专注或重置清除。距离按现有平面地图计算，不建立飞行单位或高度系统。

参考：[2024召雷术](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions#CallLightning)。
