# 战后阶段、复活与外部救援

## 进入与继续

任意一方死亡后进入战后阶段，保留地图、HP、职业资源和仍有效的法术。战斗界面左侧“战后施法 / 外部救援”打开操作面板。玩家倒地但未死亡时不算尸体；若木桩也死亡，可通过推进6秒继续死亡豁免，稳定后仍可按原规则等待自然恢复。

复活不会自动恢复战斗。双方均存活且玩家有正HP时，点击“继续战斗”推进到新回合，只刷新动作、附赠动作、普通/战术移动及反应，不回满HP、不返还职业次数、不重置法术持续时间。若时间推进导致有人再次倒地或死亡，则继续保持战后阶段。

## 当前施法入口

本批战后入口接入回生术、死者复活、遗体防腐。玩家按现有职业资格施法，须能行动、能在当前形态施法，并接近木桩尸体5尺内。战后可拖动玩家棋子接近尸体，不引发借机攻击；移动额度耗尽后可推进6秒刷新。

外部施法者只通过面板救援玩家，不占格、不参加战斗。按用户确认视为具备对应施法资格且能够接触目标，法术位仍不限。复活须确认目标灵魂愿意返回；遗体防腐不要求此确认。

施法不会等待真实的一分钟或一小时，而是推进对应的世界时间；按完成施法时检查死亡期限。长时间施法结束原有专注，若时间推进中的效果使玩家失能，则玩家施法失败。战后没有敌方自动攻击，不假造外部施法者的职业面板、属性或回合。

## 法术

- 回生术：三环，动作（6秒），接触，死亡1分钟内复活为1HP。不提供缺失器官修复，也不能复活老死者。当前训练场死亡来自已建模战斗，没有老死和器官缺失状态。
- 死者复活：五环，施法1小时，接触，死亡10天以内且死亡时非亡灵的完整尸体复活为1HP。解除现有毒素/中毒状态；d20检定减4，每次完成长休减轻1，四次后消失。重复死亡后使用回生术不会清除尚未恢复的减值，再次死者复活也不叠加成减8。
- 遗体防腐：二环，动作（6秒），尸体保护10天。保护期间不增加复活法术的有效死亡时间；到期继续计时。重新施放延长保护，不重复扣除已暂停的时间。不能变成亡灵的保护标记已记录，当前尚无尸体转化亡灵系统。

死亡计时在世界时间中进行，不随停留面板的真实时间增加。面板显示的是扣除遗体防腐保护时间后的有效死亡秒数。可按分钟等待；不稳定倒地时禁止直接跳过长时间，以免绕过死亡豁免。

## 复活减值与长休

减值影响玩家武器/自然/法术攻击、属性/技能/工具检定和所有已接入豁免，也影响木桩攻击及其法术豁免；不修改属性值、熟练值、伤害和法术豁免DC。死亡豁免的自然1/20仍按原始骰值处理。

玩家通过原休息入口完成长休减轻自身减值。战后面板提供木桩长休，8小时且24小时内至多完成一次，只减轻木桩的复活减值，并按其存活状态治疗。手动“继续战斗”不算长休。重置战斗清除战后状态、死亡时钟与复活减值。

复活术、完全复生术、转生术等其他复活法术尚未因此模块自动获得实现；法术目录继续区分状态。
