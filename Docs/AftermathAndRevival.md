# 战后阶段、复活与外部救援

## 进入与继续

任意一方死亡后进入战后阶段，保留地图、HP、职业资源和仍有效的法术。战斗界面左侧“战后施法 / 外部救援”打开操作面板。玩家倒地但未死亡时不算尸体；若木桩也死亡，可通过推进6秒继续死亡豁免，稳定后仍可按原规则等待自然恢复。

复活不会自动恢复战斗。双方均存活且玩家有正HP时，点击“继续战斗”推进到新回合，只刷新动作、附赠动作、普通/战术移动及反应，不回满HP、不返还职业次数、不重置法术持续时间。若时间推进导致有人再次倒地或死亡，则继续保持战后阶段。

## 当前施法入口

战后入口接入回生术、死者复活、复生术、遗体防腐与完全复生术。玩家按现有职业资格施法，须能行动、能在当前形态施法，并接近木桩尸体5尺内。战后可拖动玩家棋子接近尸体，不引发借机攻击；移动额度耗尽后可推进6秒刷新。

外部施法者固定为同一名角色，通过面板救援玩家或已入场的搬运救援者，不占格、不参加战斗。按用户确认视为具备对应施法资格且能够接触目标，法术位仍不限。复活须确认目标灵魂愿意返回；遗体防腐不要求此确认。

施法不会等待真实的一分钟或一小时，而是推进对应的世界时间；按完成施法时检查死亡期限。长时间施法结束原有专注，若时间推进中的效果使玩家失能，则玩家施法失败。战后没有敌方自动攻击，不假造外部施法者的职业面板、属性或回合。

## 法术

- 回生术：三环，动作（6秒），接触，死亡1分钟内复活为1HP。不提供缺失器官修复，也不能复活老死者。当前训练场死亡来自已建模战斗，没有老死和器官缺失状态。
- 死者复活：五环，施法1小时，接触，死亡10天以内且死亡时非亡灵的完整尸体复活为1HP。解除现有毒素/中毒状态；d20检定减4，每次完成长休减轻1，四次后消失。重复死亡后使用回生术不会清除尚未恢复的减值，再次死者复活也不叠加成减8。
- 遗体防腐：二环，动作（6秒），尸体保护10天。保护期间不增加复活法术的有效死亡时间；到期继续计时。重新施放延长保护，不重复扣除已暂停的时间。不能变成亡灵的保护标记已记录，当前尚无尸体转化亡灵系统。

死亡计时在世界时间中进行，不随停留面板的真实时间增加。面板显示的是扣除遗体防腐保护时间后的有效死亡秒数。可按分钟等待；不稳定倒地时禁止直接跳过长时间，以免绕过死亡豁免。

## 复活减值与长休

减值影响玩家武器/自然/法术攻击、属性/技能/工具检定和所有已接入豁免，也影响木桩攻击及其法术豁免；不修改属性值、熟练值、伤害和法术豁免DC。死亡豁免的自然1/20仍按原始骰值处理。

玩家通过原休息入口完成长休减轻自身减值。战后面板提供木桩长休，8小时且24小时内至多完成一次，只减轻木桩的复活减值，并按其存活状态治疗。手动“继续战斗”不算长休。重置战斗清除战后状态、死亡时钟与复活减值。

转生术等其他复活法术继续按法术目录区分状态，不会因共享战后入口自动获得实现。

来源：[2024回生术](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions#Revivify)、[死者复活](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions#RaiseDead)、[遗体防腐](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions#GentleRepose)。材料与仪式成分按此前项目裁定删除。

验证：Unity 2022.3.62f3c1全项目静态编译通过，RevivalChecks覆盖死亡计时、保护到期/重施、施法耗时、亡灵限制、复活HP/死亡状态/减值、长休恢复、手动继续与重置；法术清单一致性检查通过。未启动实机验证。


## 完全复生术与生前形态

完全复生术已加入战后施法/外部救援菜单：九环，施法1小时，死亡200年内且非老死的自愿目标以全部HP复活，不新增死者复活的减值，也不自动清除之前尚未恢复的复活减值。时间仍按完成施法检查，年按365天换算；当前有尸体的训练场状态接入现有毒素/中毒和脆弱诅咒清除。疾病、器官缺失、尸体消失/重建落位尚无对应的现行战斗状态，不能据此声称这些后续系统已建立。

木桩卡增加“生前”书签。生前资料包含独立的非亡灵类型、体型、六属性、最大HP、AC、熟练加值、攻击类型/距离、移动力、黑暗视觉、五组伤害骰与固定加值/伤害类型、十八项技能熟练。默认沿用项目基础怪物的默认值，可复制当前基础配置到草稿后修改；当前为亡灵时复制的生前类型暂设为类人生物并明确提示。复制不包含临时法术修正。应用只保存生前资料，不改变当前怪物。首次战斗操作后锁定编辑。

完全复生术仅在目标死亡时为亡灵的情况下恢复生前资料；普通非亡灵目标只复活，不替换基础配置。先校验原位置能否容纳生前体型，再开始施法。按用户裁定，保持当前占地左上格，不自动迁移或搜索其他位置；越界或与玩家占地重叠时禁止施法且不推进世界时间。战后地图以绿色/红色格预览生前占地，菜单同时说明是否可容纳。

成功时先恢复全部基础资料和占地，再进行满HP复活。基础HP修改不会提前把尸体治疗复活；仍有效的临时加值按各自持续时间继续计算。界面中的当前属性、伤害和技能草稿同步到恢复后的数值。仍由用户手动“继续战斗”刷新回合资源。

怪物当前属性也增加基础移动力录入（默认30尺、非负整数），以支持两个形态独立的移动资料。负熟练加值与复活减值合并采用宽整数，避免边界输入溢出。

来源：[2024完全复生术](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions#TrueResurrection)。验证增加MonsterFormChecks（独立数据、验证范围、基础恢复不提前治疗、满HP复活、200年期限与数值边界），FootprintChecks增加原位置恢复及失败不迁移；已有RevivalChecks回归通过。静态编译和法术清单一致性检查通过，未实机验证。


生前资料及当前形态另有独立挑战等级CR，采用标准CR选项（包括1/8、1/4、1/2），默认0；复制基础配置和完全复生术恢复资料时一并处理，不自动推算熟练或HP。

## 复生术和施法者疲惫

复生术为七环，一小时接触施法，死亡期限100年，排除死亡时为亡灵的目标；以当前HP上限满血复活并解除毒素／中毒，附带与死者复活相同的D20减4及长休逐次减轻。它不会移除诅咒，也不恢复亡灵的生前资料。身体缺失与老死尚无可产生的训练场状态，沿用现有边界说明。

目标实际死亡满365天时，成功施法使施法者产生独立的复生术疲惫：禁止所有施法，全部D20检定具有劣势，持续到施法者完成长休。玩家和固定外部施法者分别记录，不转移给搬运救援者；复活者自身的减4仍是另一项效果。遗体防腐延长复活期限，不改变实际死亡日期。失败施法不会追加疲惫；复活成功但仍因环境再次窒息死亡时，施法者仍会疲惫。

战后和搬运救援面板均显示固定外部施法者状态，提供“外部施法者完成长休（推进8小时）”。该操作只让外部施法者长休；世界时间、持续效果和死亡计时照常推进，玩家与搬运者不获得长休治疗或资源。每日长休收益间隔沿用24小时限制；仍有待掷死亡豁免时不能直接跳过。玩家使用原有长休入口解除自己的疲惫。返回菜单、重新打开面板及普通等待均不解除；训练场手动重置清除双方施法者状态。

外部施法者不入场，因此目前没有其可手动进行的D20操作；状态模型已保存其D20劣势。所有已接入的玩家D20路径与施法入口均应用玩家自身疲惫。来源：[2024复生术](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions#Resurrection)。
