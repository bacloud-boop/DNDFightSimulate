# 属性、技能与工具检定

玩家纹章牌的“技能”书签提供六项属性、十八项技能及三十七种工具检定。每次手动检定消耗一个动作，DC默认为10，只接受整数。自然1和20没有自动失败或成功效果；优势与劣势相互抵消，不叠加。

首次战斗操作前选择十六种背景之一，并完成初始职业、兼职职业、背景专长和专精选择，再点击应用。开始战斗后配置锁定，重置战斗后可编辑；职业改变后须重新应用。背景在本模块只提供熟练资料及相关选择，不代表背景的属性提升、装备或其他专长收益均已实现。

重复熟练按项目裁定处理：固定重复只保留一次，没有额外补选；可选项目与已有熟练重复时须在原列表内另选。同一来源不能选择相同项目。熟习可选择三项技能或工具；巧匠选择规则指定的三种工匠工具；音乐家选择三种乐器。专精仅可选择已熟练、尚未专精的合法技能。

接入职业技能及兼职授予的熟练、游荡者/吟游诗人/游侠专精、法师学者专精、吟游诗人万事通、游荡者可靠才能。战士二级战术头脑在失败后弹出选择，加1d10，只有转为成功时才消耗一次回气，不治疗且不额外消耗动作。

技能可使用辅助工具，玩家需确认工具可用且适用。技能与工具都熟练时获得优势，熟练加值仅计算一次。荒野形态使用有效属性并参考野兽的显式技能数据。工具制造、环境交互结果及职业其他未接入收益仍不由本入口自动模拟。

脆弱诅咒使所选属性检定具有劣势；猎人印记在明确选择“寻找标记目标”的察觉或求生检定中提供优势。祝福术、灾祸术和心灵之楔不作用于一般属性检定。

怪物“技能”书签可手动配置十八项技能的无熟练/熟练/专精，默认无熟练。本阶段只保存资料，不提供怪物手动检定，也不改变自动回合。

数据与来源：`Assets/Resources/Rules2024/Skills.json`记录机械事实和来源，`Tools/generate-skill-tables.py`生成编译表。规则对照官方2024基本规则职业、工具、背景与专长资料；不复制完整受版权保护的正文。

验证：Unity 2022.3.62f3c1程序集静态编译通过；`Tools/Tests/SkillChecks.cs`覆盖修正值取整、熟练与专精、背景专长、重复处理、兼职、优势抵消、可靠才能及战术头脑。未启动实机验证。
